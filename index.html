Materi Dasar HTML

1. Pengertian & Fungsi HTML

HTML (HyperText Markup Language) adalah bahasa standar yang digunakan untuk membuat dan menyusun kerangka dasar sebuah halaman web. HTML ibarat tulang belulang pada tubuh manusia yang membentuk fondasi utama.

2. Struktur Dasar HTML

Setiap dokumen HTML memiliki struktur baku sebagai berikut:

<!DOCTYPE html> <html> <head> <title>Judul Halaman Web</title> </head> <body> <h1>Halo World!</h1> <p>Ini paragraf pertama saya.</p> </body> </html>

3. Elemen dan Tag Penting

  • Heading (<h1> s/d <h6>): Digunakan untuk membuat judul atau sub-judul.
  • Paragraph (<p>): Digunakan untuk membungkus teks paragraf.
  • Image (<img>): Menampilkan gambar. Menggunakan atribut src dan alt.
  • Link (<a>): Membuat tautan ke halaman lain menggunakan atribut href.
  • List (<ul>, <ol>, <li>): Menampilkan daftar item berurutan atau tidak berurutan.

Materi Dasar CSS

1. Pengertian & Fungsi CSS

CSS (Cascading Style Sheets) adalah bahasa yang digunakan untuk mengatur tampilan visual dan tata letak halaman web. Jika HTML adalah kerangka, maka CSS adalah pakaian, warna, dan gaya.

2. Tiga Cara Penulisan CSS

  • Inline CSS: Ditulis langsung di dalam elemen HTML (contoh: style="color:red;").
  • Internal CSS: Ditulis di dalam tag <style> pada bagian <head>.
  • External CSS: Ditulis di file terpisah berekstensi .css dan dihubungkan via tag <link>.

3. Properti Dasar CSS

/* Contoh Syntax Selector, Property & Value */ body { background-color: #f8fafc; color: #1e3a8a; font-family: 'Poppins', sans-serif; } .kotak { margin: 20px; /* Jarak Luar */ padding: 15px; /* Jarak Dalam */ border: 2px solid #1e3a8a; /* Garis Tepi */ }

Materi Dasar JavaScript

1. Pengertian & Fungsi JavaScript

JavaScript (JS) adalah bahasa pemrograman yang memberikan kemampuan interaksi dinamis pada halaman web. Dengan JavaScript, web dapat merespons klik pengguna, melakukan kalkulasi, dan mengubah isi halaman secara konstan.

2. Variabel & Tipe Data

Variabel digunakan untuk menyimpan data. Dideklarasikan dengan let, const, atau var.

let nama = "Muhammad Ikram"; // Tipe String const umur = 15; // Tipe Number let isSiswa = true; // Tipe Boolean

3. Function & Event

Function adalah blok kode untuk tugas tertentu, sedangkan Event adalah aksi dari pengguna (seperti klik tombol).

// Deklarasi Function function menyapa() { document.getElementById('pesan').innerText = "Halo, Selamat Belajar JavaScript!"; }
